flowchart TD
    Start([User Clicks Refresh]) --> ValidateUI[Validate UI Selections]
    ValidateUI -->|Invalid| ShowError1[Show Validation Error<br/>Missing Required Fields]
    ShowError1 --> Cancel([Cancel Refresh])
    ValidateUI -->|Valid| TryConnectDB{Database<br/>Connection OK?}
    
    TryConnectDB -->|Failed| DBError1[Show DB Connection Error<br/>Check SQLite File]
    DBError1 --> Cancel
    TryConnectDB -->|Success| CheckFilterDB{Filter Exists<br/>in Database?}
    
    CheckFilterDB -->|Yes| TryLoadFilter{Load Filter<br/>Success?}

    DBError2 --> Cancel
    TryLoadFilter -->|Success| LoadFilter[Load Filter from DB<br/>Filters table]
    
    CheckFilterDB -->|No| ValidateFilter{Valid Filter<br/>Definition?}
    
    ValidateFilter -->|Invalid| Cancel
    ValidateFilter -->|Valid| TryCreateFilter{Create Filter<br/>Success?}
    
    TryCreateFilter -->|Failed| DBError3[DB Insert Error<br/>Transaction Failed]
    DBError3 --> Rollback1[Rollback Transaction]
    Rollback1 --> LogError1[Log Error Details]
    LogError1 --> Cancel
    TryCreateFilter -->|Success| CreateFilter[Create Filter in DB<br/>INSERT Filters<br/>IsFilterComboNew=0]
    
    CreateFilter --> TrySaveUI{Save UI State<br/>Success?}

    DBError4 --> Rollback2[Rollback Transaction]
    Rollback2 --> LogError2[Log Error]
    LogError2 --> Cancel
    TrySaveUI -->|Success| SaveUIState[Save UI State<br/>UPDATE Filters<br/>SelectedHostCategories<br/>OpeningSettings]
    
    LoadFilter --> CheckFileComboDB{FileCombo Exists<br/>in Database?}
    SaveUIState --> CheckFileComboDB
    
    CheckFileComboDB -->|Yes| TryLoadCombo{Load FileCombo<br/>Success?}
    TryLoadCombo -->|Failed| DBError5[DB Read Error]
    DBError5 --> Cancel
    TryLoadCombo -->|Success| LoadFileCombo[Load FileCombo<br/>SELECT ComboId<br/>IsFilterComboNew]
    
    CheckFileComboDB -->|No| TryCreateCombo{Create FileCombo<br/>Success?}
    TryCreateCombo -->|Failed| DBError6[DB Insert Error]
    DBError6 --> Rollback3[Rollback Transaction]
    Rollback3 --> LogError3[Log Error]
    LogError3 --> Cancel
    TryCreateCombo -->|Success| CreateFileCombo[Create FileCombo<br/>INSERT FileCombos<br/>IsFilterComboNew=1]
    
    LoadFileCombo --> DetermineRefreshPath[Determine Refresh Path]
    CreateFileCombo --> DetermineRefreshPath
    
    DetermineRefreshPath --> CheckAdopt{Adopt to Modified<br/>Document ON?}
    
    CheckAdopt -->|OFF| CheckFlag{IsFilterComboNew<br/>= 0?}
    CheckAdopt -->|ON| CheckExisting{Filter Has<br/>Existing Zones?}
    
    CheckFlag -->|Yes = 0| PATH1[PATH 1: REPLAY MODE<br/>Skip Detection]
    CheckFlag -->|No = 1| PATH2[PATH 2: FRESH PLACEMENT<br/>Run Detection]
    
    CheckExisting -->|No| PATH2
    CheckExisting -->|Yes| PATH3[PATH 3: FULL DETECTION<br/>WITH VALIDATION]

    TryLoadP1 -->|Failed| DBError7[DB Read Error<br/>or XML Parse Error]
    DBError7 --> Cancel
    TryLoadP1 -->|Success| P1_LoadZones[Load Existing Zones<br/>FROM ClashZones<br/>PRIMARY: Database<br/>FALLBACK: XML]
    P1_LoadZones --> P1_Skip[Skip Intersection<br/>Detection]
    P1_Skip --> P1_ResetFlags[Reset Flags for<br/>Deleted Sleeves Only]
    P1_ResetFlags --> P1_NoSave[No Database Save<br/>Zones Already Exist]
    P1_NoSave --> PlacementFlow
    
    %% PATH 2: FRESH PLACEMENT
    PATH2 --> TryLoadXML2{Load XML Cache<br/>Success?}
    TryLoadXML2 -->|Failed| XMLError1[XML Parse Error<br/>Invalid XML Structure]
    XMLError1 --> Cancel
    TryLoadXML2 -->|Success| P2_LoadXML[Load XML Cache<br/>OPTIONAL Fallback]
    P2_LoadXML --> TryDetect2{Intersection<br/>Detection Success?}
    TryDetect2 -->|Failed| DetectError1[Detection Failed<br/>Invalid Geometry<br/>or Missing Elements]
    DetectError1 --> LogError4[Log Error Details]
    LogError4 --> Cancel
    TryDetect2 -->|Success| P2_Detect[Run Intersection<br/>Detection<br/>MEP vs Structural]
    P2_Detect --> P2_SkipVal[Skip 3-Point<br/>Validation]
    P2_SkipVal --> P2_CreateZones[Create Clash Zones<br/>All New]
    P2_CreateZones --> TrySaveP2{Save to DB<br/>Success?}
    TrySaveP2 -->|Failed| DBError8[DB Insert Error<br/>Transaction Failed]
    DBError8 --> Rollback4[Rollback Transaction]
    Rollback4 --> LogError5[Log Error]
    LogError5 --> Cancel
    TrySaveP2 -->|Success| P2_SaveDB[Save to Database<br/>INSERT ClashZones<br/>INSERT SleeveSnapshots<br/>FileCombo flag stays = 1]
    P2_SaveDB --> TryCommitP2{Commit<br/>Transaction<br/>Success?}
    TryCommitP2 -->|Failed| DBError9[Commit Failed<br/>DB Lock or Constraint]
    DBError9 --> Rollback5[Rollback Transaction]
    Rollback5 --> LogError6[Log Error]
    LogError6 --> Cancel
    TryCommitP2 -->|Success| P2_Commit[Commit Transaction]
    P2_Commit --> PlacementFlow
    
    %% PATH 3: FULL DETECTION WITH VALIDATION
    PATH3 --> TryLoadXML3{Load XML Cache<br/>Success?}

    XMLError2 --> Cancel

    DetectError2 --> LogError7[Log Error]
    LogError7 --> Cancel
    TryDetect3 -->|Success| P3_Detect[Run Intersection<br/>Detection<br/>MEP vs Structural]
    P3_Detect --> TryValidate{3-Point<br/>Validation Success?}
    TryValidate -->|Failed| ValidateError[Validation Failed<br/>Element Access Error]
    ValidateError --> LogError8[Log Error]
    LogError8 --> Cancel
    TryValidate -->|Success| P3_Validate[3-Point Validation<br/>For Each Existing Zone:<br/>1. MEP Element Exists?<br/>2. Structural Element Exists?<br/>3. Elements Still Intersect?]
    
    P3_Validate --> P3_Split[Split Zones by Result<br/>- All Pass = Validated<br/>- Any Fail = Invalidated<br/>- Not in Existing = New]
    
    P3_Split --> P3_Validated[Validated Zones<br/>Route to PATH 1 Logic]
    P3_Split --> P3_Invalidated[Invalidated Zones<br/>Needs Merge & Update]
    P3_Split --> P3_New[New Zones<br/>Route to PATH 2 Logic]
    
    P3_Invalidated --> P3_Merge[Merge Required<br/>Update Intersection Points<br/>Handle Moved Elements]
    P3_Merge --> TrySaveInval{Save Invalidated<br/>Zones Success?}
    TrySaveInval -->|Failed| DBError11[DB Update Error]
    DBError11 --> Rollback6[Rollback Transaction]
    Rollback6 --> LogError9[Log Error]
    LogError9 --> Cancel
    TrySaveInval -->|Success| P3_SaveInval[Save Invalidated Zones<br/>UPDATE ClashZones<br/>Updated Geometry]
    P3_SaveInval --> TryCommitP3{Commit<br/>Transaction<br/>Success?}

    DBError12 --> Rollback7[Rollback Transaction]
    Rollback7 --> LogError10[Log Error]
    LogError10 --> Cancel
    TryCommitP3 -->|Success| P3_Commit[Commit Transaction]
    
    P3_Validated --> PlacementFlow
    P3_New --> PlacementFlow
    P3_Commit --> PlacementFlow

    PlacementFlow[Determine Placement Path] --> CheckPlacementPath{Which Path<br/>Route?}
    
    CheckPlacementPath -->|PATH 1<br/>Replay| P1_Placement
    CheckPlacementPath -->|PATH 2<br/>Sizing| P2_Placement

    CheckPlacementPath -->|PATH 3<br/>Invalidated| P3_Inval_Placement

    P1_CheckConditions -->|No| TryLoadPlace1{Load Zones<br/>Success?}

    LogError11 --> Cancel

    P1_Loop --> P1_CheckSleeve{Sleeve Exists?<br/>MEP+Host+Point}
    P1_CheckSleeve -->|Yes| P1_Skip[Skip - Already Placed]
    P1_CheckSleeve -->|No| TryPlace1{Place Sleeve<br/>Success?}

    PlaceError1 --> LogError12[Log Error]
    LogError12 --> P1_Loop
    TryPlace1 -->|Success| P1_Place[Place Sleeve<br/>Using Saved Data]
    
    P1_Place --> TryUpdateFlags1{Update Flags<br/>Success?}
    TryUpdateFlags1 -->|Failed| FlagError2[Flag Update Error]
    FlagError2 --> LogError13[Log Error]
    LogError13 --> P1_Loop
    TryUpdateFlags1 -->|Success| P1_UpdateFlags[Update Flags<br/>IsResolved = true<br/>SleeveInstanceId]

    LogError21 --> Cancel
